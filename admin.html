AJ · Product & Rate Editor

For Ayyanar Jewellers. Prepare your gold/silver catalogue and today’s rates, then download the updated JSON files and commit them to GitHub. This is a local editor; it cannot silently change the live site.

Publishing & security: This page is a browser-side editor, not an authenticated admin dashboard. Other visitors can open this page if they know its URL, but they cannot edit your GitHub repo through it. Keep GitHub access private. No product data is uploaded until you manually commit the exported files.

1 · Load existing data

To edit products already published, choose the downloaded products.json file from your repository. Rates are stored separately in rates.json. Your browser saves draft changes locally.

2 · Update rates (₹/gram)

These values are manually maintained. They are not an automatic feed from Thangamayil. Confirm the shop rate before publishing.

3 · Add or edit a jewellery product

Photos: upload your image file into the repository folder assets/products/ separately. Then enter its path above. No watermark or fake product photos. Quantity is inventory metadata; displayed price is per piece.

Estimated price: ₹0

4 · Current products

Click Edit to change an existing product or Remove to remove it from your exported product list. For designs embedded in the original HTML, use “Remove existing design ID” below.

5 · Export to GitHub

For a real inventory, selecting this option is recommended after you have added all your products. Otherwise these products are added to the original illustrative jewellery catalogue.

Commit new products.json and rates.json to the root of your GitHub repository. Upload any product images to assets/products/ first. When Netlify redeploys, the website reads the new files automatically. Nothing is changed on the live site before commit.
